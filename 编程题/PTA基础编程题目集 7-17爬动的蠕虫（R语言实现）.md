# 7-17 爬动的蠕虫（R语言实现）

## 前言

## 题目描述

一条蠕虫长1寸，在一口深为N寸的井的底部。已知蠕虫每1分钟可以向上爬U寸，但必须休息1分钟才能接着往上爬。在休息的过程中，蠕虫又下滑了D寸。就这样，上爬和下滑重复进行。请问，蠕虫需要多长时间才能爬出井？

这里要求不足1分钟按1分钟计，并且假定只要在某次上爬过程中蠕虫的头部到达了井的顶部，那么蠕虫就完成任务了。初始时，蠕虫是趴在井底的（即高度为0）。

## 输入格式

输入在一行中顺序给出3个正整数N、U、D，其中D<U，N不超过100。

## 输出格式

在一行中输出蠕虫爬出井的时间，以分钟为单位。

## 输入样例

```in
12 3 1
```

## 输出样例

```out
11
```

## 解题思路

- **核心问题分析**：蠕虫交替进行上爬（1分钟上升U寸）和休息（1分钟下滑D寸），需要计算爬出井所需的总时间。关键在于：上爬过程中若到达或超过井口即完成，不需要再下滑。
- **算法原理说明**：使用模拟法，通过无限循环交替执行上爬和休息两个阶段。每次上爬后立即检查是否爬出，若已爬出则退出循环；否则进入休息阶段下滑。时间在每个阶段分别累加。
- **具体计算步骤**：
  1. 初始化高度height=0，时间time=0
  2. 进入循环：
     - 上爬阶段：time+1，height+U，若height≥N则结束
     - 休息阶段：time+1，height-D
  3. 重复步骤2直到爬出井
  4. 输出总时间time

## 完整代码

```r
# 爬动的蠕虫：模拟蠕虫交替进行上爬（1分钟上升U寸）和休息（1分钟下滑D寸），直到爬出深N寸的井

inp <- scan(file = "stdin", what = integer(), quiet = TRUE)  # 使用scan读取井深N、上爬距离U、下滑距离D（file="stdin"）
N <- inp[1]  # 井深
U <- inp[2]  # 上爬距离
D <- inp[3]  # 下滑距离
time <- 0  # 时间，初始为0
height <- 0  # 当前高度，初始为0

while (TRUE) {  # 无限循环，直到蠕虫爬出井
    time <- time + 1  # 时间加1分钟
    height <- height + U  # 蠕虫上爬U寸
    if (height >= N) {  # 判断是否到达或超过井口
        break  # 爬出井，退出循环
    }
    
    time <- time + 1  # 休息1分钟，时间加1
    height <- height - D  # 休息期间下滑D寸
}

cat(sprintf("%d\n", time))  # 使用cat/sprintf输出爬出井的总时间
```

## 代码流程说明

1. **R 脚本顶层代码**（第1行起）：R 是脚本语言，无需 main 函数与头文件，代码自上而下执行，注释使用 `#`。
2. **变量声明与输入**（第3-8行）：定义井深N、上爬距离U、下滑距离D、时间time（初始0）、当前高度height（初始0）；使用 `scan(file = "stdin", ...)` 从标准输入读取 N、U、D 三个正整数。
3. **模拟循环**（第10-19行）：
   - `while (TRUE)` 进入无限循环
   - 上爬阶段：time 自增1分钟，height 增加 U 寸
   - 判断 height ≥ N：若成立则 break 退出循环（已爬出）
   - 休息阶段：time 自增1分钟，height 减少 D 寸（下滑）
4. **输出**（第21行）：`cat(sprintf("%d\n", time))` 使用 `cat()`/`sprintf()` 向标准输出打印总时间 time（无多余空格）。
